# 🍴 Zomato Sales Analysis – SQL Project

## 📌 Project Overview

This project focuses on analyzing a Zomato sales database using **MySQL**.

The database contains information about customers, restaurants, food items, employees, orders, order details, and payments. The project uses SQL queries to solve real-world business problems and generate meaningful insights from the data.

## 🎯 Project Objective

The main objective of this project is to:

- Analyze customer ordering behavior
- Identify top-performing restaurants and food items
- Analyze revenue and payment trends
- Evaluate delivery performance
- Identify popular food items
- Analyze employee delivery ratings
- Understand order trends and customer behavior

## 🛠️ Tools & Technologies

- **MySQL**
- **SQL**
- Joins
- Aggregate Functions
- GROUP BY & HAVING
- Subqueries
- CTEs
- Window Functions
- Date & Time Functions
- CASE Statements

## 🗂️ Database Tables

The database contains the following tables:

- `customer` – Customer information
- `restaurant` – Restaurant details and ratings
- `zomato_employee` – Delivery employee information
- `foods` – Food items and prices
- `order_detail` – Order and delivery information
- `order_food` – Food items included in each order
- `payment_table` – Payment information

## 🔍 Key Business Questions

Some of the major questions solved in this project:

1. Find the top 3 customers based on number of orders.
2. Identify the restaurant with the highest average rating.
3. Find orders delivered in under 30 minutes.
4. Calculate revenue generated by each food item.
5. Find the second-highest revenue-generating restaurant.
6. Identify the 5 most popular food items by quantity sold.
7. Find the top 3 employees based on delivery ratings.
8. Identify the month with the highest number of orders.
9. Calculate the average order amount for each customer.
10. Find the most frequent customer for each restaurant.
11. Calculate weekend orders.
12. Compare average delivery time on weekdays vs weekends.
13. Find the top 5 most expensive food items.
14. Identify the restaurant with the most diverse menu.
15. Analyze total payment amount by payment type.
